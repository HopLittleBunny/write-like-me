# Security

## Supported version

Security fixes are applied to the latest published release candidate or stable release.

## Reporting

For non-sensitive problems, open a GitHub issue. Do not paste private drafts, writing samples, profiles, credentials, or personal diagnostic output into a public issue.

For a vulnerability that would expose user content, enable instruction execution from samples, bypass a semantic blocker, or leak local files, use the repository's private security-advisory reporting flow when available.

## Scope

Write Like Me has no independent backend. The main security boundaries are local file handling, untrusted text inside writing samples, diagnostic redaction, package integrity, and the behaviour of the AI host in which the skill runs.
